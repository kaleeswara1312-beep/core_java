Golden Rule of Java Concurrency

Thread.sleep() pauses execution while RETAINING ALL LOCKS. Other threads remain blocked waiting for the monitor.
Object.wait() pauses execution while RELEASING MONITOR LOCK, allowing other threads to enter the synchronized block.

Thread.sleep(1000) LOCK HELD (No Release)

Thread-A sleeps inside synchronized block. Thread-B attempts to enter and is BLOCKED.

Monitor Lock Status: Held by Thread-A
Thread-A → TIMED_WAITING (Holding Lock)
Thread-B → BLOCKED (Locked Out!)
object.wait(1000) LOCK RELEASED

Thread-A calls wait(). Releases monitor lock. Thread-B acquires lock and becomes RUNNABLE.

Monitor Lock Status: Released to Thread-B
Thread-A → WAITING (In Wait Set)
Thread-B → RUNNABLE (Acquired Lock & Executing)
